# SignalHub v1 data sources

The first seeded account is Schneider Electric in Manufacturing / India. The initial URLs are official Schneider Electric pages for company information, newsroom, investor relations, annual reporting, India newsroom, and careers.

Current public material visible from the official site includes 2026 newsroom items around AI-ready data-center infrastructure, energy/industrial intelligence, partnerships, and India energy/digital initiatives. These are used only as source material; SignalHub should preserve the original source URL and distinguish observation from inference.

For news discovery, SignalHub uses the public GDELT DOC 2.0 API. GDELT documents that the DOC 2.0 API supports JSON output and article-list search over recent coverage. This is a discovery layer, not a substitute for primary-source verification.
